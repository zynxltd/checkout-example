# YouGarden — Spin the wheel

Promo wheel demo for on-site campaigns. Weighted prizes, one spin per browser session, copyable discount codes.

## Prizes

- 10% off (`SPIN10`)
- Free delivery (`FREESHIP`)
- Free seeds (`SEEDGIFT`)
- £5 off £30 (`YG5OFF`)
- 15% off (`SPIN15`)
- Club trial (`CLUB30`)
- Try again / Almost (no code)

## Run

```bash
cd demos/yougarden-spin-wheel
npm install
npm run dev
```

Open **http://127.0.0.1:5178**
