# YouGarden — Pip mascot site

Professional themed scroll site: **same mascot (Pip)** in every section, each with a **different animated background**.

| Section | Background | Pip |
|---------|------------|-----|
| Hero | Soft sky + clouds | Wave |
| Establish | Soil + sprouts | Dig |
| Maintain | Rain + mist | Water |
| Enjoy | Falling leaves | Carry |
| Club | Dusk light | Cheer |

## Run

```bash
cd demos/garden-mascot-site
npm install
npm run dev
```

Open **http://127.0.0.1:5177**
