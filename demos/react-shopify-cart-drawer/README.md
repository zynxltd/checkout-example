# Smart cart drawer + upsells (React / Shopify-style)

**P0 pick** from React / Shopify stack. Stand-in for a Theme App Extension / Hydrogen cart drawer.

## Run

```bash
cd demos/react-shopify-cart-drawer
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Demo script

1. Add Trail Boots (£32) → drawer opens, £8 to free shipping
2. Accept Care Kit bundle → meter completes
3. Toggle qty / close / reopen cart
