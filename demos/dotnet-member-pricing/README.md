# Member pricing engine (.NET + C#)

**P0 pick** from .NET + C# stack.

## Run

```bash
cd demos/dotnet-member-pricing
dotnet run
```

Open http://127.0.0.1:5088

1. Add plants → quote API returns guest vs member lines
2. Toggle member → savings strip updates
3. Add mower → 7.5% machinery rate
4. Confirm “pays for itself” when saving ≥ £10
