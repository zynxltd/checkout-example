# Northline — ASP.NET Core website

Standard marketing website built with **ASP.NET Core Razor Pages**.

## Pages

- `/` Home (full-bleed hero)
- `/About`
- `/Services`
- `/Contact` (validated form)
- `/Privacy`

## Run

```bash
cd demos/aspnet-standard-website
dotnet run --launch-profile http
```

Open http://localhost:5171

HTTPS profile:

```bash
dotnet run --launch-profile https
```
