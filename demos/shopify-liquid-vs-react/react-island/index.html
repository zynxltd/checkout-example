Is dusk.com Liquid or React?

Liquid theme (Shopify Online Store) — not a Hydrogen/React storefront. Evidence from live headers/HTML: powered-by: Shopify, Shopify.theme (Underscore schema), shopify-section, shop duskretail.myshopify.com.

React can still appear as app extensions / islands (search, reviews, badges). The page shell is still Liquid-rendered HTML.
