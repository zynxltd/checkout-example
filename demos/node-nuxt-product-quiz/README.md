# Product quiz → cart (Node.js + Nuxt)

**P0 pick** from Node.js + Nuxt stack.

## Run

```bash
cd demos/node-nuxt-product-quiz
npm install
npm run dev
```

Open http://127.0.0.1:3000

## Demo script

1. Answer 4 quiz steps
2. See ranked matches from Nitro `/api/quiz/score`
3. Add top match → cart bar updates
4. Retake or note shareable result id
